# Delhivery Graph-Based Network Intelligence

## Objective
Improve ETA prediction accuracy and identify bottlenecks in Delhivery's logistics network using graph analytics.

## Dataset
- 144,867 shipment records
- 1,590 logistics hubs
- 2,508 directed corridors

## Models

| Model | MAE |
|---------|---------|
| Baseline | 53.40 |
| Corridor + Hub | 38.39 |
| Graph Model | 38.31 |

## Key Deliverables
- Graph Construction
- Bottleneck Hub Analysis
- Corridor Delay Analysis
- ETA Prediction
- FTL vs Carting Framework
- Network Operations Strategy Memo

## Repository Structure

- notebooks/
- graphs/
- outputs/
- reports/

## Results

Graph-enhanced intelligence reduced ETA prediction error from 53.40 MAE to 38.31 MAE while identifying critical bottleneck hubs and delay corridors for operational intervention.
